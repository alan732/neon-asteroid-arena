# Neon Last Stand

A polished 3D browser arena shooter built with Three.js.

## Play

Open `index.html` in a modern browser, or serve the repository with a static web server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Controls

- **WASD** — Move
- **Mouse** — Aim
- **Left mouse** — Fire
- **Shift** — Dash
- **E** — Pulse

## Features

- Procedural neon arena
- Three enemy classes and boss waves
- Dash and shock-pulse abilities
- Health pickups and enemy projectiles
- Responsive HUD, audio, particles, and screen damage feedback
